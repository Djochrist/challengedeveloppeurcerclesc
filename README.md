# Challenge Développeur

Landing page officielle du Cercle Scientifique Math-Info de l’UNILU.

## Stack

HTML, CSS et JavaScript natifs. Aucune dépendance ni compilation.

## Lancer le projet

```bash
python3 -m http.server 5000
```

Ouvrir ensuite `http://localhost:5000`.

## Personnaliser

Modifier `CONFIG` et `quizContent` dans `script.js` pour mettre à jour le formulaire, la date limite ou les sujets.

## Déployer

Le dossier est prêt à être publié sur GitHub Pages, Vercel ou tout hébergeur de fichiers statiques. Pour Vercel, utiliser le répertoire racine sans commande de build.
